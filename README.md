# Role-Based Sustainable Apple Supply Chain Management System

This project is a backend system built using ASP.NET Core Web API to manage apple collection, grading, and distribution between apple owners and companies.

## Features
- Apple collection requests
- Apple grading system (A, B, C, D)
- Admin approval workflow
- Company purchase requests
- Payment confirmation
- Stock management
- Prevents negative inventory

## Technologies
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication
- Clean Architecture (Controller-Service-Repository)

## Roles
Admin – manages requests, grading stock and users  
Apple Owner – submits apple collection requests  
Students – collect apples from owners  
Companies – request apples and complete purchase
